# 📌 Projeto – Gerenciamento de Praias e Bairros de Florianópolis
## 📖 Descrição

Este projeto foi desenvolvido como Trabalho de Conclusão de Curso no SENAI / SESC, com o objetivo de criar uma aplicação para o gerenciamento de bairros e praias de Florianópolis/SC.

A aplicação permite o cadastro, consulta, atualização e exclusão (CRUD) de informações, integrando Front-End e Back-End por meio de uma API REST, seguindo boas práticas de desenvolvimento e organização de código.

## 🎯 Objetivos do Projeto
- Aplicar na prática os conceitos estudados durante o curso
  
- Desenvolver uma API RESTful organizada e escalável
  
- Integrar Front-End com Back-End
  
- Utilizar boas práticas de arquitetura em camadas
  
- Simular um cenário real de aplicação utilizada em um produto digital

## 🧩 Funcionalidades

- Cadastro de bairros

- Cadastro de praias

- Listagem de bairros e praias

- Edição de registros

- Exclusão de registros

- Relacionamento entre bairros e praias

- Consumo de API via requisições HTTP

## 🏗️ Arquitetura

O projeto segue o padrão de arquitetura em camadas, facilitando a manutenção e evolução da aplicação:

- Controller: responsável pelas requisições HTTP

- Service: regras de negócio e validações

- Repository: acesso e persistência de dados

## 🖥️ Front-End

- Desenvolvimento de interfaces web para interação com a API

- Consumo de endpoints REST (GET, POST, PUT, DELETE)

- Organização de componentes e estrutura do código

- Foco em usabilidade e clareza das informações

Tecnologias:

- HTML

- CSS

- JavaScript

## ⚙️ Back-End

- Desenvolvimento de API REST utilizando Java e Spring Boot

- Implementação de regras de negócio e validações

- Persistência de dados com Spring Data JPA

- Banco de dados PostgreSQL

Tecnologias:

- Java

- Spring Boot

- Spring MVC

- Spring Data JPA

- PostgreSQL

## 🛠️ Ferramentas Utilizadas

- Git e GitHub (versionamento)

- IDE de desenvolvimento

- Banco de dados relacional

## 🚀 Como executar o projeto (Back-End)

1. Clonar o repositório

2. Configurar o banco de dados PostgreSQL

3. Ajustar as configurações no application.properties

4. Executar a aplicação Spring Boot

5. Acessar os endpoints via navegador ou ferramenta como Postman

## 📚 Contexto Acadêmico

Este projeto foi desenvolvido com fins educacionais, simulando um ambiente real de desenvolvimento de software, com foco em boas práticas, organização e integração entre camadas.
